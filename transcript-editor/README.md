# 녹취록 편집기 (맥북용 · Claude 연동)

녹취 텍스트를 붙여넣으면 **원본 정리 → 맥락 분석 → 후속 제안 → A4 미리보기 → PDF**까지 한 화면에서 처리하는 문서 편집기입니다.

> **비유로 이해하기**
> - 편집기 화면은 **책상**, Claude는 **외부 전문가**입니다.
> - 맥에서 돌아가는 작은 서버(`server.mjs`)는 책상 옆 **전화 교환대**입니다. 전문가의 직통번호(API 키)는 교환대 서랍에만 있고, 책상(웹페이지) 위에는 올라오지 않습니다.
> - 교환대는 **내 맥 안에서만(127.0.0.1)** 열려 있어 같은 와이파이의 다른 사람은 걸 수 없습니다.

## 1. 처음 한 번 준비

1. **Node.js 18 이상** 설치: <https://nodejs.org/ko/download> (이미 있으면 건너뜀)
2. **Anthropic API 키** 발급: <https://console.anthropic.com> → API Keys (`sk-ant-`로 시작)

## 2. 실행

`녹취록편집기.command` 를 **더블클릭**하면 터미널 창이 열리고 브라우저에 편집기가 뜹니다. 끝낼 때는 터미널 창을 닫으세요.

- 처음 실행하면 구성요소를 자동 설치합니다(인터넷 필요, 1분 이내).
- "확인되지 않은 개발자" 경고가 뜨면: 파일을 **우클릭 → 열기 → 열기**.
- 그래도 안 열리면 터미널에서:
  ```bash
  cd 이_폴더_경로 && chmod +x 녹취록편집기.command && ./녹취록편집기.command
  ```

## 3. 키 설정

편집기 왼쪽 **① 원본·변환 → Claude 연동 → 키 설정** 에 키를 붙여넣고 저장합니다.

- 키는 `~/.transcript-editor/config.json`(본인만 읽기 가능, 권한 600)에 저장됩니다. 삭제 버튼으로 지울 수 있습니다.
- 환경변수 `ANTHROPIC_API_KEY` 가 있으면 그것을 우선 사용합니다.
- `ant auth login` 으로 로그인해 두었다면 키 없이도 시도합니다.

## 4. 사용 흐름

| 단계 | 하는 일 |
|---|---|
| ① 원본·변환 | 텍스트 붙여넣기·파일(txt, md, srt, vtt)·음성 입력 → **분석 엔진** 선택 → `변환·정리 실행` |
| ② 맥락 분석 | 결정·할 일·미해결·질문과 답변·수치, Claude의 **오인식 교정 내역** 확인 |
| ③ 후속 제안 | 우선순위가 붙은 제안 선택 → 문서 4번에 반영, **공문·메일 초안** 생성 |
| ④ 사실 대조 | 정리문의 각 문장이 원본 발언에 근거하는지 Claude가 검증 → 문서에 색 막대로 표시 |
| 문서 | 문장을 드래그하고 **✦ AI 편집**: 간결하게·공문서체·쉬운 말·원본 기준 교정·직접 지시 |
| 출력 | 편집 / 분할 / 미리보기, `PDF 저장 / 인쇄`(인쇄 창에서 **PDF로 저장**), HTML·Markdown 내보내기 |

**분석 엔진**
- ⚡ **내장 규칙**: 무료·즉시. 키워드와 패턴 기반이라 거친 정리입니다.
- ✦ **Claude 분석**: 맥락을 이해해 주제를 나누고, 근거 발언 번호와 함께 정리합니다. 실패하면 내장 규칙 결과를 그대로 남깁니다.

**모델**: 기본은 Opus 5.5(권장). Sonnet 5.5(빠르고 저렴), Haiku 5.5(가장 저렴)로 바꿀 수 있습니다. `생각 깊이`는 빠르게/보통/깊게.

## 5. 비용 감각

호출 뒤 왼쪽 상자에 **입력·출력 토큰과 추정 비용**이 표시됩니다. 대략 한 시간 분량(약 3만 자) 녹취를 Opus 5.5로 분석하면 수백 원 안팎입니다. 단가는 변동될 수 있으니 콘솔의 사용량을 기준으로 보세요. 사실 대조와 AI 편집도 각각 호출 1회입니다.

## 6. 개인정보·보안

- 녹취 내용은 **Claude 분석·대조·편집·초안을 실행할 때에만** Anthropic API로 전송됩니다. 내장 규칙 모드에서는 어디로도 나가지 않습니다.
- 서버는 `127.0.0.1` 에서만 열리며, 다른 주소·다른 출처에서 오는 요청은 거절합니다.
- 민감한 녹취(실명·연락처 등)는 보내기 전에 마스킹하는 것을 권장합니다.
- Opus 5.5는 안전 정책으로 응답을 거절할 수 있어 서버 쪽 대체 모델(`fallbacks: "default"`)을 켜 두었습니다.

## 7. 문제 해결

| 증상 | 해결 |
|---|---|
| "서버 없이 열린 상태" | `index.html` 을 직접 연 경우입니다. `.command` 로 실행하세요. |
| "API 키가 올바르지 않거나 만료" | 키 설정에서 다시 입력. 결제·한도를 콘솔에서 확인 |
| "요청이 많아 잠시 제한" | 1분 뒤 재시도, 또는 Sonnet 5.5 선택 |
| 응답이 잘렸다는 메시지 | 원본을 나눠 실행하거나 Sonnet 5.5 선택 |
| 포트 사용 중 | 자동으로 다음 번호(4174…)를 씁니다. 터미널에 뜬 주소를 확인하세요. |
| PDF 인쇄 창이 안 뜸 | `HTML 저장` 후 저장된 파일을 열면 인쇄 창이 자동으로 뜹니다. |

## 파일 구성

- `index.html` — 편집기 화면(단독으로 열면 내장 규칙 모드로만 동작)
- `server.mjs` — 로컬 서버 + Claude 호출(공식 `@anthropic-ai/sdk`)
- `녹취록편집기.command` — 맥 더블클릭 실행 파일
